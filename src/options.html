ℹ️ Utilisation

Raccourci clavier : Ctrl+Shift+T (Windows/Linux) ou Cmd+Shift+T (Mac)

Comment utiliser :
  1. Sélectionnez du texte dans un email
  2. Clic droit → "Traduire en français (DeepL)"
  3. Ou utilisez le raccourci clavier
  4. La traduction apparaît dans une notification
Fonctionnalités :
  • Traduction vers le français
  • Copie de la traduction dans le presse-papiers
  • Remplacement du texte sélectionné (dans une fenêtre de composition)
  • Raccourci clavier personnalisable
